Overview

About This Project

A PHP OOP-based Gym Management platform that streamlines member registration, membership plans, trainer management, and fee tracking. It offers a responsive public website for members and visitors, while giving administrators full control over members, packages, attendance, and gym operations from one centralized panel.

Highlights

Key Features

Admin Panel:


  1. Admin login with session-based authentication
  2. Member management (add, edit, view profiles)
  3. Membership plans and packages management
  4. Trainer management
  5. Fee and payment records tracking
  6. Attendance management
  7. Contact messages inbox
  8. PDF, CSV, and Print report generation
  9. System settings and configuration
  10. DataTables for fast data handling
  11. Secure admin session and navbar
