About This Project

Doctor MCQs is an online medical exam preparation platform built for doctors preparing for MRCGP INT South Asia AKT & OSCE exams. It offers high-yield MCQs, timed mock tests, OSCE scenarios, eBooks, and recorded sessions, all aligned with the latest curriculum and guidelines in one student-focused learning hub.

Highlights

Key Features

  1. Secure student registration and login
  2. Large MCQ / SBA question bank with detailed explanations
  3. Timed mock tests with real exam-style interface
  4. OSCE scenarios for clinical exam practice
  5. eBooks and study resources for flexible learning
  6. Recorded sessions and on-demand video lessons
  7. Curriculum-aligned content with latest guidelines (NICE, WHO & local)
  8. Category-wise packages and exam-focused study plans
  9. Progress tracking and result insights
  10. Fully responsive design for web and mobile access
  11. Admin panel for managing questions, packages, and content
