Overview

About This Project

A PHP OOP-based Vehicle Parking Management platform that streamlines vehicle check-in and checkout, parking charge calculation, and receipt generation. It includes a browser-based setup wizard and gives administrators full control over vehicle categories, parked vehicles, reports, and site settings from one centralized panel.

Highlights

Key Features

Admin Panel:


  1. Browser-based installation wizard with database and admin setup
  2. Admin login with session-based authentication
  3. Dashboard with daily check-in/check-out counts and revenue summary
  4. Vehicle category management with hourly parking rates
  5. Incoming vehicle check-in, edit, and checkout workflow
  6. Outgoing vehicle records with view and delete actions
  7. Automatic parking charge calculation and printable receipts
  8. Overstay alert system with configurable hour limit
  9. Parking reports with date filters and Excel, PDF, Print export
  10. Repeat visitor auto-fill by registration number
  11. Admin profile and site settings (name, logo, currency)
  12. DataTables, toast notifications, and responsive admin UI
