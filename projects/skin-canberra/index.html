Overview

About This Project

Skin Canberra is a Laravel web application for an advanced skin and laser clinic. It delivers a public website for treatments, online appointment booking, and training courses, plus an admin panel for managing content, bookings, customers, and Stripe payments in AUD - with email notifications for booking updates, reminders, and course purchases.

Highlights

Key Features

  1. Public clinic website with a CMS-managed homepage (hero slides, feature blocks, treatments, premium items, promo cards, trust items, and testimonials)
  2. Services catalogue with parent/child grouping, sortable order, variants, and configurable price display
  3. Online appointment booking with available time slots, holiday handling, and slot capacity limits
  4. Booking request workflow with admin approval, a 25% Stripe advance deposit, and remaining-balance payment
  5. Admin weekly calendar, appointment list, client search, and quick-book tools
  6. Contact form with admin enquiry management
  7. CMS-managed About, Contact, Privacy Policy, and Terms pages
  8. Member registration and login, with a dashboard for appointments, profile, and password changes
  9. Paid training courses with Stripe checkout, video access, and secure PDF download
  10. Admin management for services, service times, holidays, courses, customers, testimonials, certificates, and site settings
  11. Email notifications for booking requests, approvals, declines, reschedules, deposits, and course purchases
  12. Scheduled 48-hour appointment reminder emails, with reminder logs in the admin panel
  13. Stripe Checkout payments in AUD
  14. Image uploads converted to WebP using Intervention Image
